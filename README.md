# MegaSchool_task3
система из нескольких AI-агентов, которая проводит техническое интервью, имитируя поведение реального рекрутера, и (самое главное) «мыслит» перед ответом.


## 1. Установка зависимостей
Установите необходимые пакеты с помощью pip. Список зависимостей:

- `langchain` — для цепочек промптов.
- `langchain_mistralai` — интеграция с Mistral AI.
- `langgraph` — для графа состояний.

Команда установки:

`pip install langchain langchain-mistralai langgraph`


## 2. Настройка API-ключа Mistral
Получите API-ключ на сайте Mistral AI. Установите его в переменные окружения:

`export MISTRAL_API_KEY="your_mistral_api_key_here"`

В идеале ключ берется из файла с помощью `os.environ["MISTRAL_API_KEY"]` и у нас сохраняется безопасность ключа. Однако у меня ключ прописан в самом коде

`os.environ["MISTRAL_API_KEY"] = "M6OSvBa27krOBulBhhMqloA5YUnA2Ds7"`.

чего делать конечно же нельзя, но времени было немного. Поэтому тебе дорогой читатель придется тоже вставлять ключ напрямую в код

## 3. Запуск кода


Запустите: `python main5.py`.
Следуйте инструкциям в консоли: ответьте на приветствие (имя, позиция, грейд, опыт), ведите диалог, завершите командой "Стоп интервью".

### Пример запуска:

Введите позицию (например, Backend Developer): Backend Java

Введите грейд (например, Junior): Junior

Введите опыт (например, Пет-проекты на Django, немного SQL): SQL, Django 

Начните интервью, представившись и описав свой опыт.
